# Security Policy

## Scope

This project contains defensive documentation, a local inventory validator,
and Ansible examples for Debian/Ubuntu support servers. It is not intended to
connect to or manage energy production or OT equipment.

## Reporting a vulnerability

Please do not publish exploit details, site inventories, credentials, or
operational network information in a public issue. Use GitHub's private
vulnerability reporting feature for this repository if it is enabled. If
private reporting is unavailable, contact the maintainers through a private
channel listed in the repository profile and share only the minimum details
needed to reproduce the issue in an isolated test environment.

Do not test this project against systems you do not own or have explicit
written authorization to assess. Do not include real site data in reports.

## Supported versions

Only the latest version on the default branch is currently supported. This
project has not yet established a release or security-response SLA.
